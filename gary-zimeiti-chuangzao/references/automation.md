# Codex 夜间采集

在 Codex 桌面端通过正式的 Automations 功能设置，复用已有匹配任务。用户授权过的默认采集窗口为北京时间每日 00:00–05:00。按半小时分批，00:00 开始，04:30 起最后一批。按平台的调度能力选择该窗口，在提示词里额外核对北京时间，处理延迟触发或临近结束的情况。

## 配置与验收

1. 确认目标本地聊天或项目能访问 Vault、ego(lite) 能启动且保有用户的正常登录状态。已有同用途的任务优先更新，避免重复启动。
2. 任务第一步读取项目及 Vault 的现有规范、库首页、归档标准与近期采集记录。每批延续本日记录，先检查已有作品 ID，优先联网取证，轮换细分行业。正式选题研究的 30 条初筛目标可累积完成，夜间单批处理量由对口样本与可用时间决定。
3. 每批完成一条就写入。临近终点停止开启新检索，保存核实结果和待查项。遇到登录、验证、ego 未连接或外部限流，记录具体页面、完成进度与待处理事项。下次续采前先去重。
4. 创建或更新后核对启用状态、时区、首批及末批时间。首次夜间实际触发后，再核对时间、浏览器可用性、入库和结束记录。任务启用与实际采集成功分别报告。

## 可用于自动化的任务正文

每天北京时间 00:00 起分批维护当前 Obsidian 婚嫁获客选题库。每次触发先核对时间，05:00 及以后立即结束。读取本地规范和当日记录，用 ego 联网搜索婚嫁细分行业获客内容。优先近一周对口低粉高互动的作品，按作品 ID 去重。核实作者、日期、公开互动、原观点和可见最高赞三条评论。能合法取得音轨时用本地 ASR 生成带时间戳的口播逐字稿。每确认一条就按行业写入 Obsidian，缺项写明理由。接近 05:00 时保存已完成的卡片和待查列表并结束。当天无合格作品也如实记下。此任务只采集和归档。
