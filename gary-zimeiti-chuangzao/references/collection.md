# 采集与 Obsidian 归档

## 确认本地位置

优先沿用用户现有 Vault、库首页、作品卡格式和栏目。新建时可以使用下面的目录。文件名中的作品 ID 用字符串保存，避免长数字被舍入。

```text
<Vault>/
  03外部资料收集/
    婚嫁获客选题库/
      00 婚嫁获客选题库.md
      作品卡/<产业板块>/<细分行业>/<作品ID>.md
      每日采集/YYYY-MM-DD.md
    婚嫁数字人口播文案/
      YYYY-MM-DD 选题名.md
```

在用户已有的行业表里匹配细分行业。新库可从婚宴与婚礼场地、婚礼策划与统筹、婚礼设计与搭建、花艺、派对、主持演艺、摄影影像、妆造、礼服、珠宝、宴会餐饮、婚品、婚车与接待、婚俗、现场技术、道具供应链、婚旅、渠道工具、商家经营服务、婚前消费逐步建立分类。按作品讲的商家选主分类，需要时用属性记录关联行业。

## 联网核查及转写

1. 读本机 ego-browser Skill 并运行其版本对应的使用指南。在 ego 的同一个任务空间内搜索行业、获客问题和各个候选观点。用户要看过程时把任务空间切到前台。
2. 初筛记录作者、标题、页面显示日期、赞数和链接。进入关键候选详情，核对原链接、发布日期、作者粉丝与点赞、收藏、分享、评论。只记录可见指标，页面约数保留其精度。
3. 评论区优先核对可见范围内按点赞排序的前三条，记录评论原文、赞、回复数和作者发言标记。评论加载不全、并列、图片评论或暂无评论时如实标注。围绕候选观点额外寻找实质追问和反对意见。
4. 优先使用页面可用字幕。需语音转写时，用 ego 正常播放、识别该页面已加载的音轨或通过站方允许的下载入口提取素材。对于可合法获取的媒体，在本机用 ffmpeg 抽取单声道音轨，通过现有本地 ASR 生成带时间戳的逐字稿。标记机器转写，关键观点、数字和拟引用语句要回听。无法播放、下载或转写时说明缺项并继续核查可读样本。验证由用户在 ego 内处理。
5. 对标音视频作为转写中间文件处理。确有保存需要且具备使用权限时才入本地素材附件目录。凭据、登录会话标识和带临时访问参数的音轨地址不写入 Vault、日志或 GitHub。

## 作品卡

沿用库内现有属性名。每次以作品 ID 去重。已有卡按日期追加数据变化和新发现的评论，避免覆盖此前快照。单条作品完整核实即入库，当日采集笔记链接新卡和待查项。

```yaml
---
标题: ""
类型: "婚嫁对标作品"
平台: "抖音"
作品ID: ""
产业板块: ""
行业: ""
受众: ""
话题: ""
博主: ""
状态: "选题待验证"
发布日: ""
核验日: ""
---
```

正文保留原视频链接、可见互动、原标题与开头、各候选观点及时间点、可见热评、逐字稿或相对路径、适用范围与待验证事项。已核实的数字填进属性，隐藏数值保留为未知。只计符合互动标准、来源和内容均已核验的独立爆款文案作为 1,000 条进度。未来要统计前先写明对应行业爆款的可比口径，方法旁证单独存放。

## 成稿

用户已经确认归档的口播进入「婚嫁数字人口播文案」，与选题库同级。按原文保存正文、封面和话题，可加入行业、归档日期、制作状态及来源卡链接。候选稿留在工作区，按用户的审稿规则进入制作目录。
